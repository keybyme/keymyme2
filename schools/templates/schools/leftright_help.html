Lefts & Rights — Help

How to find/print a guide, and how to fill one out.

{% include "icons/map-pin.html" with class="w-4 h-4" %} Lefts & Rights

1. Finding and printing a guide

  1. Open Lefts & Rights from the top menu.
  2. Pick a Route from the dropdown — only routes that already have at least one guide show up there.
  3. Click a guide's name to open it. That's the printable page: turn-by-turn directions, one line per step, with the direction icons described below.
  4. Any line that starts with STOP @ is a stop — the underlined address opens driving directions (Apple/Google Maps) from wherever you are right now, whenever you tap it.
  5. Print prints just the route sheet — no menu, no buttons, nothing else.
  6. Back returns to the list with that same route already selected.

Back on the list, the pencil and trash icons next to a guide's name let you edit or delete it. Add Left & Right creates a new one — type a Route (free text, doesn't need to match any other catalog) and a Name for this particular guide (one route can have several, e.g. different times of day), then Save. It starts you off with four blank rows to build from — see below.

2. Row types

Every guide is a list of rows on the edit page, each with a Type:

  • Title — big, bold, centered text. Used for headers like the route number or "*** POST TRIP BUS NOW ***".
  • Bold — bold black text.
  • Normal — bold gray text. Most turn-by-turn lines use this one.
  • Link — for a "STOP @" row: three fields side by side (Text, Address, Text after). The Address becomes the clickable GPS link described above.

3. The direction-letter trick

On a Normal or Bold row, type a single letter, several spaces, then the street name:

R     MAIN ST → {% include "icons/turn-right.html" with class="w-5 h-5 text-gray-700" %} MAIN ST
L     MAIN ST → {% include "icons/turn-left.html" with class="w-5 h-5 text-gray-700" %} MAIN ST
S     MAIN ST → {% include "icons/straight.html" with class="w-5 h-5 text-gray-700" %} MAIN ST
U     MAIN ST → {% include "icons/u-turn-left.html" with class="w-5 h-5 text-gray-700" %} MAIN ST

On the printed page, R/L/S/U turn into a Right/Left/Straight/U-turn icon instead of the bare letter — easier to read at a glance while driving. It only kicks in with a wide gap (several spaces) right after the letter — a single space, or the letter being part of a real word ("RIGHT", "STOP"), is left completely alone.

4. Adding rows

  • {% include "icons/plus.html" with class="w-3 h-3" %} Insertar fila — adds a blank Normal row.
  • {% include "icons/plus.html" with class="w-3 h-3" %} Insertar vinculo — adds a blank Link (STOP @) row.
  • {% include "icons/plus.html" with class="w-3 h-3" %} Post Trip — adds a 3-row block: a blank row, a "*** POST TRIP BUS NOW ***" title row, then another blank row.

The # (optional) field next to those buttons controls where the new row(s) land: leave it blank to add at the end, or type the sequence number shown to the left of an existing row (e.g. 35) to insert there instead — between #30 and #40, in this example. Existing rows keep their numbers; nothing else is renumbered. The field clears itself after each use.

The trash icon on a row removes it — but like everything else on this page, that only actually takes effect once you click Save. Cancel discards anything not yet saved (you'll get a warning if you try to navigate away — top nav, Cancel, browser back — with unsaved changes).
